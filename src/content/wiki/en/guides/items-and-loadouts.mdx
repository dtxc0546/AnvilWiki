## Where do you find your loadout?

Look for Items while waiting in the lobby. The [recorded walkthrough](https://games.resuhive.com/survive-your-ideas/guide) shows the Loadout area beside the collection, with five visible slots. Use the lobby countdown to give yourself time to read the current screen before the match begins and you need to move.

| Lobby area | What to check |
| --- | --- |
| Items collection | Which items are already available to you |
| Loadout | Which slots are visible and what the current screen says |
| Match countdown | Whether you have time to read another item description |

## What should you look for in an item description?

Start with a problem you have actually encountered. If a climb was hard to reach, look for a description that explains how the item affects movement. If you struggled to recover after taking damage, look for a relevant effect and read any conditions shown in the game.

| Problem to solve | Question to ask before testing |
| --- | --- |
| Reaching high ground | Will the described effect help with the approach, the jump, or the landing? |
| Escaping a blocked route | Can you activate the item while following an alternate path? |
| Recovering after a mistake | When can you use the item, and what does the screen say it changes? |

## How can you test whether a loadout helps?

Pick one item and one scenario to observe in your next match. Note where you were when you tried the item, what the game showed after you used it, and whether the result helped you reach safety. Repeat when you can so an easier arena layout does not skew your impression.
