# Launch editorial evidence

Each topic starts with a player task, questions, and a claim matrix. Add direct game evidence before treating reported rewards, item effects, prices, odds, and update details as confirmed. Keep citations beside claims that could affect a player's decision. Record inaccessible sources and missing evidence explicitly.

Keep the codes report in draft until an in-game test. Keep code redemption as a research topic within that draft until it warrants a separate page. Steam and mod platforms are outside this Roblox site's scope.

| English term | Editorial usage |
| --- | --- |
| writer | The player selected to enter a word |
| word | The input entered during a writing turn |
| hazard | A dangerous effect in the arena |
| Codes | The lobby panel as reported in walkthroughs |
| Lucky Spin | Singular reward or menu label |
| Lucky Spins | Plural reward quantity |
| Word Mastery | Update feature name |
